Help

Installing & FAQ

Windows says "Windows protected your PC"

The installer isn't code-signed yet, so Windows SmartScreen warns about it the first time. Click More info, then Run anyway. Updates after that install on their own.

macOS won't open the app

Open the .dmg and drag Sapphire Client into Applications. The first time, right-click the app and choose Open. If macOS says the app "is damaged", run this in Terminal once:

xattr -cr "/Applications/Sapphire Client.app"

How do I run the Linux AppImage?

Make it runnable, then start it: chmod +x SapphireClient_*.AppImage and ./SapphireClient_*.AppImage. Prefer a package? Use the .deb, .rpm or Flatpak instead.

Do I need to own Minecraft?

Yes. Sign in with the Microsoft account that owns Minecraft: Java Edition. Sapphire Client downloads and launches the game, but doesn't include or sell it.

What data do you collect?

Nothing. We don't collect anything: no accounts, analytics or tracking. The launcher only talks to the services it needs, like Microsoft for sign-in and Modrinth for mods. See the Privacy Policy for the full list.

Can I bring my instances from another launcher?

Yes. Choose New instance → Import to bring instances over from launchers like Prism or the Modrinth App, or open a file someone exported from Sapphire Client.
